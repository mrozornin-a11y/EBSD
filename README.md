# Реконструкция полюсных фигур EBSD

Настольная программа (Python 3.11+, PySide6) для полуавтоматического извлечения полюсных
фигур EBSD из растровых изображений (JPG, PNG, TIF, TIFF), в том числе из больших составных
рисунков научных статей, их очистки и перерисовки в публикационном качестве.

Программа **не восстанавливает исходные экспериментальные данные и не создаёт новых точек**:
она переносит существующие цветные пиксели и кластеры на чистую фигуру, сохраняя их
нормированные координаты и цвет.

## Возможности

| Этап | Что делается |
|---|---|
| 1. Изображения | Загрузка одного или нескольких изображений (диалог, перетаскивание, аргументы командной строки). 8/16-битные, RGBA, многостраничные TIFF. |
| 2. Разметка | Автопоиск окружностей (OpenCV), перетаскивание, изменение радиуса, удаление, ручное добавление (центр + точка на окружности, с привязкой к линии), уточнение по изображению. Назначение образца, зерна и индекса плоскости; массовое назначение и автогруппировка по расположению. |
| 3. Группировка | Дерево «образец → зерно → фигуры», перетаскивание между зёрнами и образцами, порядок фигур, правка индексов, сетка, расстояние, диаметр, предпросмотр. |
| 4. Реконструкция | Два режима (точный / повышение читаемости), все параметры с живым предпросмотром, общие или индивидуальные настройки, сравнение с оригиналом бок о бок, ручная правка маски. |
| 5. Экспорт | Отдельная фигура, зерно, все зёрна образца, пакетно все образцы. PNG, TIFF (с DPI 300/600/1200 или любым), SVG и PDF (окружности, оси и подписи — векторные). |
| Проект | Формат `.ebsdproj` (JSON): ссылки на изображения (относительные и абсолютные пути) или встроенные изображения, окружности, атрибуты, параметры, правки масок, настройки экспорта, текущий этап. Резервная копия `.bak`, автосохранение каждые 2 минуты и восстановление после сбоя, запрос при закрытии с несохранёнными изменениями. |

## Установка и запуск

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

Можно сразу передать файлы: `python main.py рисунок.png проект.ebsdproj`.
В Linux/macOS команды аналогичны (`source .venv/bin/activate`).

## Сборка EXE для Windows

Запустите `build_exe.bat`. Скрипт создаст окружение `.venv`, установит зависимости
(`requirements-dev.txt`), прогонит тесты и соберёт программу PyInstaller по `ebsd_pf.spec`.
Результат: `dist\EBSD_PoleFigures\EBSD_PoleFigures.exe`. Для переноса копируйте всю папку
`dist\EBSD_PoleFigures`.

## Тесты

```bash
pip install -r requirements-dev.txt
pytest -q tests
```

Тесты используют генератор синтетических составных рисунков (`tests/synthetic.py`) с известной
«истиной»: полюсные фигуры с осями (оси поверх точек и под ними), кластеры разного размера
и цвета, одиночные пиксели, отвлекающие элементы (залитый круг, окружность без осей, буква «O»,
цветное кольцо, эллипс с осями, незамкнутая дуга, подпись) и сжатие JPEG разного качества.

Проверяется: обнаружение всех фигур и отбраковка отвлекающих элементов (в т.ч. после JPEG),
точность центра/радиуса, поиск мелких окружностей на больших изображениях, полнота выделения
кластеров и отсутствие ложных, субпиксельное сохранение центроидов при переносе, увеличении
пикселей и кластеров и при уменьшении, отсутствие новых цветов, отчётность об удалённом шуме,
восстановление кластера под осью, ручные правки маски, компоновка и подписи, экспорт во все
форматы с корректным DPI и масштабом SVG, сохранение/загрузка проекта, сквозной сценарий GUI.

## Как это работает

### Поиск окружностей (`ebsd_pf/core/detection.py`)
1. Маска тёмных линий (низкая яркость и хроматичность).
2. Кандидаты по октавным полосам радиусов: каждая полоса обрабатывается на своей уменьшенной
   копии (радиус ≈ 12 пикс.) — контуры маски и преобразование Хафа.
3. Уточнение на исходном разрешении: по 90–720 радиальным лучам находится середина линии
   окружности, затем робастная МНК-подгонка окружности с отбрасыванием выбросов (осей).
4. Признаки полюсной фигуры: линия замкнута (≥ 85 %), тонкая, внутри преобладает фон,
   присутствуют горизонтальная и вертикальная оси (отключаемо). Так отсекаются буквы, маркеры,
   залитые круги, эллипсы, дуги и цветные кольца.
5. Подавление дублей и вложенных окружностей.

### Выделение точек (`ebsd_pf/core/segmentation.py`)
* Пиксель — кандидат, если его хроматичность или отличие от уровня фона превышает порог.
  Учёт отличия от фона нужен потому, что JPEG (субдискретизация цвета 4:2:0) обесцвечивает
  одиночные цветные пиксели — их цвет восстановить нельзя, но сама точка сохраняется;
  такие объекты подсчитываются как «ахроматические».
* Положение и толщина линии окружности и осей определяются по профилям. В окрестности линий
  принимаются только явно цветные пиксели (бахрома JPEG у чёрных линий отбрасывается).
* Части кластера, перекрытые осевой линией, восстанавливаются только если кластер одного
  цвета виден по обе стороны линии (отключаемо, пиксели подсвечиваются зелёным).
* Фильтр шума по минимальному размеру объекта: по умолчанию выключен (1 пикс.), насыщенные и
  тёмные объекты защищены от удаления, все удалённые объекты перечисляются в статистике и
  обводятся пурпурным на оригинале. **Незаметного удаления точек нет.**
* Ручная правка маски: кисти «Добавить» (только не-фоновые пиксели оригинала), «Исключить»,
  «Ластик», отмена. Правки хранятся в нормированных координатах окружности.

### Перенос на новую фигуру (`ebsd_pf/core/layer.py`)
* Координаты нормируются на центр и радиус окружности: `(x − cx)/r`.
* Точный режим: пиксели переносятся без изменения формы и цвета; при уменьшении применяется
  прямой перенос каждого пикселя, поэтому одиночные точки не пропадают.
* Режим читаемости: «размер пикселей» — симметричная дилатация каждого пикселя (цвет — от
  ближайшего исходного пикселя), «увеличение кластеров» — масштабирование каждого кластера
  вокруг его собственного центроида. Центры не смещаются (проверено тестами, < 0,75 пикс.).
  Насыщенность (HSV), контраст относительно белого фона, обрезка ореолов JPEG, сглаживание
  или единый цвет кластера. Слияние кластеров при сильном увеличении сообщается.

### Оформление и экспорт (`ebsd_pf/core/render.py`, `exporter.py`)
Белый фон, чёрные окружности одинаковой толщины, тонкие оси, подпись `{hkl}` над окружностью
или у её верхнего края — прямоугольник подписи гарантированно не пересекает круг, поэтому
точки не перекрываются. Все фигуры зерна одного диаметра, отступы одинаковые; сетка 2×2 для
четырёх фигур, автоматическая сетка для других количеств. Экран и экспорт используют один
и тот же код отрисовки (QPainter), поэтому предпросмотр совпадает с результатом.

## Структура проекта

```
main.py                     точка входа (и для PyInstaller)
ebsd_pf/app.py              журнал, обработка исключений, запуск
ebsd_pf/core/               обработка без GUI
  models.py                 модель данных и параметры
  imageio_utils.py          загрузка/сохранение изображений
  geometry.py               подгонка окружностей, вырезки, порядок чтения, кластеризация
  detection.py              поиск окружностей
  segmentation.py           выделение точек
  layer.py                  перенос точек на новую фигуру
  pipeline.py               хранилище изображений, кэш (потокобезопасно)
  render.py                 компоновка и отрисовка (QPainter)
  exporter.py               экспорт PNG/TIFF/SVG/PDF
  project_io.py             формат проекта .ebsdproj
ebsd_pf/gui/                интерфейс PySide6 (экраны, виды, фоновые задачи)
tests/                      автотесты и генератор синтетических изображений
```

Длительные операции (загрузка, поиск, предпросмотр, экспорт) выполняются в пуле потоков,
интерфейс не блокируется. Журнал: `%LOCALAPPDATA%\EBSDPoleFigures\logs\ebsd_pf.log`
(меню «Справка → Открыть папку журнала»).

## Ограничения

* Цвет одиночных пикселей, уничтоженный сжатием JPEG, не восстанавливается (это было бы
  созданием данных); такие точки сохраняются с фактическим (серым) цветом и подсчитываются.
* Полюсные фигуры с заливкой плотности (контурные карты) выделяются, но программа рассчитана
  прежде всего на точечные фигуры.
* Оси предполагаются горизонтальной и вертикальной.
